# NumberFieldIntegralBasis

!!! success "Status: Stable"
    documented, exercised by the test suite and/or worked examples, with no known limitations recorded.

## Description

**`NumberFieldIntegralBasis[a]`**

gives an integral basis for the field Q(a) generated by the algebraic number a: a list of algebraic integers that generate the ring of integers O\_K of Q(a) as a module over the integers.  The equation order Z\[a\] is enlarged to O\_K by Round 2 (Pohst-Zassenhaus) when it is not already maximal, so the basis is correct for non-monogenic fields.  a may be a radical, a Root object, or an AlgebraicNumber object; the basis it produces may not be unique.  Threads over lists.  Requires FLINT. Attributes: Listable, Protected.

## Examples (5)

Every input below was run against the current Mathilda build and its output recorded.

### Basic examples (5)

Q(2^(1/3)), monogenic

```mathematica
In[1]:= N[NumberFieldIntegralBasis[2^(1/3)]]
Out[1]= {1.0, 1.25992, 1.5874}
```

Z[theta] not maximal

```mathematica
In[2]:= N[NumberFieldIntegralBasis[Sqrt[2] + Sqrt[3]]]
Out[2]= {1.0, 3.14626, 5.44949, 13.3706}
```

Z[zeta_8]

```mathematica
In[3]:= N[NumberFieldIntegralBasis[E^(I Pi/4)]]
Out[3]= {1.0, 0.707107 + 0.707107*I, 6.12323e-17 + 1.0*I, -0.707107 + 0.707107*I}
```

```mathematica
In[4]:= AlgebraicIntegerQ /@ NumberFieldIntegralBasis[E^(I Pi/4)]
Out[4]= {True, True, True, True}
```

Threads over lists

```mathematica
In[5]:= N[NumberFieldIntegralBasis[{Sqrt[2], Sqrt[5]}]]
Out[5]= {{1.0, 1.41421}, {1.0, 1.61803}}
```

## Algorithm

numberfieldintegralbasis.c — NumberFieldIntegralBasis[a].

See numberfieldintegralbasis.h for the contract. All field / maximal-order computation is delegated to flint_qqbar_integral_basis (which builds the algebraic-integer generator, runs the number-field layer's Dedekind + Round 2 maximal-order engine, and renders each basis row as a canonical AlgebraicNumber). This file only checks the argument shape and reports a decline; the evaluator re-canonicalises each returned element on its next fixed-point step.
