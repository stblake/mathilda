# BesselI

!!! success "Status: Stable"
    documented, exercised by the test suite and/or worked examples, with no known limitations recorded.

## Description

**`BesselI[n, z]`**

gives the modified Bessel function of the first kind I\_n(z), the solution of z^2 y'' + z y' - (z^2 + n^2) y = 0 regular at the origin.

**`D[BesselI[n, z], z] = (BesselI[n-1, z] + BesselI[n+1, z])/2. Listable.`**

<details>
<summary>Notes</summary>

I\_0(0) = 1, I\_n(0) = 0 for integer n != 0; I\_n grows like e^z as z -\> Inf and is even in n (I\_{-n} = I\_n). Has a branch cut along the negative real z axis for non-integer n. Real and complex order and argument evaluate numerically at machine or arbitrary (MPFR) precision;

</details>


## Implementation notes

**Algorithm.** `builtin_besseli` (via `besseli_two_arg`) handles `BesselI[n, z]`, the modified Bessel function of the first kind, the solution of `z^2 y'' + z y' - (z^2 + n^2) y = 0` regular at the origin. Exact `z == 0` with classified order gives `I_0(0) = 1`, `I_n(0) = 0` (`Re nu > 0` or `n` a negative integer), `ComplexInfinity` (non-integer `Re nu < 0`), or `Indeterminate` (`Re nu = 0`). MPFR has no modified-Bessel routine, so the whole numeric path is the unified core `bi_core`: the **power series** (the same one-Gamma recurrence as `J`, via the shared `bk_iseries`, but without the `(-1)^k` sign — all terms positive) for small/moderate `|z|`, and the **asymptotic series** DLMF 10.40.5 (`I_nu(z) ~ e^z/sqrt(2πz) Sum (-1)^k a_k/z^k`, valid on the whole principal sheet) for large `|z|`, summed to optimal truncation. Half-integer→elementary rewrites live in `src/internal/bessel.m`; `Series`/`D` in `calculus/`. Everything else stays symbolic.

**Data structures.** `Expr`; the shared complex-MPFR toolkit `ncpx` (`numeric_complex.h`) at explicit working precision; machine results overflowing a `double` are promoted to MPFR. The ND kernel is a binary `REG_B` registration (`NDKB_BesselI`, generated by `NDK_BIN2` → `sf_machine_bessel_i` in `src/special_functions/sf_machine.c`): element-wise over real arrays, declining complex operands to the `List` path. `Compile[]` lowers `BesselI[n, z]` at scalar (`Compiled -> True`, `ResultType -> Real`) and rank-1 array shapes via that kernel.

**Complexity / limits.** Series/asymptotic term counts and guard bits scale with `|z|` and precision. Branch cut along the negative real `z` axis for non-integer order. Symbolic arguments stay symbolic. Attributes: `Listable`, `NumericFunction`, `Protected`.

**Attributes:** `Listable`, `NumericFunction`, `Protected`.
