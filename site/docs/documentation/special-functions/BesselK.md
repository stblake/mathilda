# BesselK

!!! success "Status: Stable"
    documented, exercised by the test suite and/or worked examples, with no known limitations recorded.

## Description

**`BesselK[n, z]`**

gives the modified Bessel function of the second kind K\_n(z), a solution of z^2 y'' + z y' - (z^2 + n^2) y = 0.

**`D[BesselK[n, z], z] = -(BesselK[n-1, z] + BesselK[n+1, z])/2. Listable.`**

<details>
<summary>Notes</summary>

K\_n(z) is even in n (K\_{-n} = K\_n) and decays like e^{-z} as z -\> Inf. K\_0(0) = Infinity, K\_n(0) = ComplexInfinity. Has a branch cut along the negative real z axis. Real and complex order and argument evaluate numerically at machine or arbitrary (MPFR) precision;

</details>

## Implementation notes

**Algorithm.** `builtin_besselk` (via `besselk_two_arg`) handles `BesselK[n, z]`, the modified Bessel function of the second kind, which diverges at the origin: `K_0(0) = Infinity`, `K_nu(0) = ComplexInfinity` for every other order. MPFR has no modified-Bessel routine, so the whole numeric path is the unified core `bk_core`, routing by region: the **asymptotic series** DLMF 10.40.2 (`K_nu(z) ~ sqrt(π/(2z)) e^{-z} Sum_k a_k/z^k`) for large `|z|` at any order; the **connection formula** DLMF 10.27.4 (`K_nu(z) = (π/2)(I_{-nu}(z) - I_nu(z))/sin(nu π)`) for small `|z|`, non-integer order; and the **logarithmic series** DLMF 10.31.1 for small `|z|`, integer order (where the connection is a `0/0` limit). Half-integer→elementary rewrites live in `src/internal/bessel.m`; `Series`/`D` in `calculus/`. Everything else stays symbolic.

**Data structures.** `Expr`; the shared complex-MPFR toolkit `ncpx` (`numeric_complex.h`) at explicit working precision; machine results overflowing a `double` are promoted to MPFR. The ND kernel is a binary `REG_B` registration (`NDKB_BesselK`, generated by `NDK_BIN2` → `sf_machine_bessel_k` in `src/special_functions/sf_machine.c`): element-wise over real arrays, declining complex operands to the `List` path. `Compile[]` lowers `BesselK[n, z]` at scalar (`Compiled -> True`, `ResultType -> Real`) and rank-1 array shapes via that kernel.

**Complexity / limits.** Series/asymptotic term counts and guard bits scale with `|z|` and precision. Diverges at the origin for every order; branch cut along the negative real `z` axis. Symbolic arguments stay symbolic. Attributes: `Listable`, `NumericFunction`, `Protected`.

**Attributes:** `Listable`, `NumericFunction`, `Protected`.
