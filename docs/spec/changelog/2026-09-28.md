# Changelog: week of 2026-09-28 (Mon) – 2026-10-04 (Sun)

## `Pause`, `SessionTime`, `TimeUsed`, `$TimeUnit` (v0.218)

Added `Pause[n]`, which blocks for at least `n` seconds of wall-clock time and
returns `Null`, together with the three symbols its documentation references.

- **`Pause[n]`** — sleeps on `nanosleep` (a wall-clock timer that consumes no
  CPU), resuming across signal interruptions so the full duration is always
  observed. The argument is coerced to a machine double via a robust path that
  accepts integers, reals, bignums, rationals (`Pause[1/4]`), MPFR reals, and
  any `NumericQ` symbolic form (`Pause[Pi]`); zero/negative returns immediately
  and a non-numeric argument leaves `Pause[x]` unevaluated. Attribute
  `Protected`. Implemented in `src/datetime.c`; `SYM_Pause` interned in
  `src/sym_names.c`.
- **`SessionTime[]`** — wall-clock seconds since kernel start-up, from the same
  monotonic clock (`clock_gettime(CLOCK_MONOTONIC)`) used by `AbsoluteTiming`,
  measured against a baseline captured in `datetime_init()`.
- **`TimeUsed[]`** — CPU seconds used so far this session, via `clock()`.
- **`$TimeUnit`** — read-only real constant, `1 / CLOCKS_PER_SEC`, the
  resolution of the `clock()`-based timers and the granularity `Pause`
  documents itself against. Registered in `system_constants_init()`
  (`src/core.c`).

**The counted/not-counted semantic falls out of the existing two-clock design.**
`Timing`/`TimeUsed` read CPU time (`clock()`), which does not advance during a
`nanosleep`, so `Pause` is invisible to them (`Timing[Pause[1]]` ≈ `{0, Null}`).
`AbsoluteTiming`/`SessionTime` read the monotonic wall clock, so `Pause` is fully
counted (`AbsoluteTiming[Pause[1]]` ≈ `{1.0, Null}`). No special-casing is
needed; the two clock sources do the accounting.

Tests: `tests/test_datetime.c` gains coverage for the `Null` return, the
"at least `n` seconds" wall-clock guarantee, `Protected` attribute, symbolic
non-evaluation, the CPU-invisible / wall-counted split, and the three helpers.
